Native NVIDIA Broadcast (USB & Wi-Fi)

NVIDIA Broadcast Nativo (USB e Wi-Fi)

Includes CameraPhone Virtual Camera, a DirectShow driver written from scratch in modern C++ with native 4K NV12 media pins. Use NVIDIA's AI Background Blur, Auto-Frame, and Eye Contact over USB cable or wireless Wi-Fi without needing OBS open.

Inclui o driver DirectShow CameraPhone Virtual Camera com pinos nativos NV12 até 4K. Use Desfoque de Fundo por IA, Auto-Frame e Contato Visual no NVIDIA Broadcast via Cabo USB ou Wi-Fi sem precisar abrir o OBS.

Native OBS Studio Plugin

Plugin Nativo do OBS Studio

A dedicated 64-bit C++ OBS plugin (cameraphone.dll). Provides free red-handle resizing, Alt-drag cropping, Chroma Key, color LUTs, and studio tally lights right inside OBS.

Plugin C++ 64-bit dedicado (cameraphone.dll). Permite redimensionar livremente pelas alças vermelhas, recortar com Alt, Chroma Key, LUTs de cor e luz de Tally no OBS.

Up and Running in 60 Seconds

Pronto em 60 Segundos

No accounts, no cloud setup, and no driver headaches. Everything is self-contained.

Sem contas, sem nuvem e sem dor de cabeça com drivers. Tudo pronto e automático.

STEP 01

Run CameraPhone-Setup.exe

Execute o Instalador Windows

Installs the Windows companion app, registers the DirectShow Virtual Camera for NVIDIA Broadcast, and provisions the native OBS Studio 64-bit plugin.

Instala o aplicativo no Windows, registra a Câmera Virtual para o NVIDIA Broadcast e instala o plugin 64-bit nativo no OBS Studio.

STEP 02

Click "2. Install APK on Phone"

Clique em "2. Install APK on Phone"

Plug your phone in via USB once with USB Debugging enabled. The PC companion installs the APK, grants camera permissions, and caches your Wi-Fi IP automatically.

Conecte o celular via USB uma vez com Depuração USB ativa. O PC instala o APK, concede permissões de câmera e salva o IP Wi-Fi automaticamente.

STEP 03

Select in NVIDIA Broadcast or OBS

Selecione no NVIDIA Broadcast ou OBS

Choose CameraPhone Virtual Camera in NVIDIA Broadcast / Discord, or add CameraPhone 4K Pro in OBS Studio. Works via USB Cable or Wi-Fi!

Escolha CameraPhone Virtual Camera no NVIDIA Broadcast / Discord, ou adicione CameraPhone 4K Pro no OBS Studio. Funciona via USB ou Wi-Fi!
